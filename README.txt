PWA Icons
=========

Add two PNG icons here for the Progressive Web App:

  icon-192.png   → 192 × 192 pixels
  icon-512.png   → 512 × 512 pixels

You can create simple solid-color icons or use any free icon generator
(e.g. https://favicon.io or https://realfavicongenerator.net).

Until you add real icons, the browser may show a default placeholder.
The app still works without custom icons.
